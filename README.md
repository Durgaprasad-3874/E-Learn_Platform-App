# SkillUp — E-Learning Platform

Responsive React + Vite demo with React Router, search, category filters, course detail pages, enrollments, progress tracking, and LocalStorage persistence.

## Run locally
1. Install Node.js (18+ recommended).
2. Extract the ZIP.
3. Open a terminal in this folder.
4. Run `npm install`
5. Run `npm run dev`
6. Open the URL printed by Vite (usually `http://localhost:5173`).

## Preview on your phone
**Quickest option:** upload this project to a GitHub repository and import it into StackBlitz or deploy it with Vercel/Netlify. Open the resulting preview/deployment URL on your phone.

**Same Wi-Fi option:** run `npm run dev -- --host 0.0.0.0` on your computer, find its local IP address, then open `http://YOUR-COMPUTER-IP:5173` in your phone's browser. Keep both devices on the same Wi-Fi and allow the development server through your firewall if asked.

The ZIP is source code, not a directly installable iPhone app. Login/register are demo-only and use LocalStorage; do not enter a real password or sensitive information.
